# FitChecker

Calorie checker + BMI-based fitness coach. Built with Expo SDK 57, Expo Router and expo-sqlite. Dark-first neon UI.

```bash
npm install
npx expo start      # i / a / w
npm test            # domain unit tests
```

Full documentation (architecture, data model, formulas, coach rules, design system, roadmap): **[PROJECT_DOCS.md](./PROJECT_DOCS.md)**
